# 📱 Entrelinhas - Guia de Instalação no Celular

O **Entrelinhas** agora é um **PWA (Progressive Web App)** totalmente funcional e pode ser instalado como um aplicativo nativo em seu smartphone!

## 🚀 Como Instalar

### 📲 iPhone/iPad (iOS 15+)
1. Abra a URL do app em **Safari**
2. Clique no botão **Compartilhar** (ícone de caixa com seta)
3. Selecione **"Adicionar à Tela Inicial"**
4. Nomeie como desejar (sugestão: "Entrelinhas")
5. Clique em **Adicionar** no canto superior direito
6. O app aparecerá na sua tela inicial!

### 🤖 Android
#### Opção 1: Chrome Browser (Recomendado)
1. Abra a URL em **Google Chrome**
2. Clique no ícone de **três pontos** (menu) no canto superior direito
3. Selecione **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**
4. Confirme a instalação
5. O app será adicionado à tela inicial com ícone próprio

#### Opção 2: Firefox
1. Abra a URL em **Mozilla Firefox**
2. Clique no ícone de **três linhas** (menu) no canto superior direito
3. Selecione **"Instalar"**
4. Confirme a instalação

#### Opção 3: Samsung Internet
1. Abra a URL em **Samsung Internet**
2. Toque no ícone de **menu** (três linhas ou três pontos)
3. Selecione **"Adicionar à tela inicial"**
4. Confirme

### 💻 Desktop/Laptop (Navegadores Desktop)
1. Abra a URL em **Chrome, Edge ou Firefox**
2. Procure o ícone de **instalação** na barra de endereços (geralmente à direita)
3. Clique em **"Instalar Entrelinhas"**
4. Confirme a instalação
5. O app será aberto em uma janela separada

## ✨ Recursos do PWA

✅ **Funciona Offline** - Use mesmo sem conexão de internet
✅ **Dados Salvos Localmente** - Seu progresso fica armazenado no dispositivo
✅ **Sem Anúncios** - Experiência limpa e focada
✅ **Rápido** - Interface super responsiva
✅ **Usa Menos Dados** - Após a primeira carga, consome muito pouco
✅ **Notificações** - Pode receber lembretes (quando habilitado)

## 🔄 Sincronização de Dados

Todos os seus dados (progresso das sessões, histórico de energia, reflexões) são salvos localmente no seu dispositivo em um banco de dados IndexedDB. Isso significa:

- **Privacidade Total**: Seus dados nunca saem do seu dispositivo
- **Persistência**: Os dados continuam salvos mesmo após desinstalar/reinstalar
- **Backup Manual**: Você pode exportar seus dados se necessário

## 🐛 Resolução de Problemas

### O app não aparece para instalar?
- Certifique-se de que está usando um navegador moderno (Chrome 78+, Firefox 55+, Safari 15.1+)
- A URL deve estar servida via HTTPS (em localhost funciona também)
- Tente limpar o cache/cookies do navegador

### Os dados não estão sendo salvos?
- Verifique se o navegador permite IndexedDB (não está em modo privado)
- Certifique-se de que o service worker está registrado (verifique o console do desenvolvedor)

### Como desinstalar?
- **iPhone**: Mantenha pressionado o ícone > "Remover App" > "Remover da Tela Inicial"
- **Android**: Mantenha pressionado o ícone > "Desinstalar" ou "Remover"
- **Desktop**: Menu do app > "Desinstalar"
